# POLARCONNECT Data

This folder contains **prototype/demo data only** for the POLARCONNECT PS-60 project.

It is NOT official operational data for Indian Antarctic research stations.

Files included:

- `station_profiles.json` — demo station configuration for Maitri and Bharati
- `system_thresholds.json` — demo warning/critical thresholds
- `sensor_config.json` — sensor/system mapping
- `sample_sensor_readings.csv` — sample time-series readings
- `sample_weather.csv` — sample Antarctic weather inputs
- `simulation_scenarios.json` — ready-to-run demo scenarios
- `maintenance_log_sample.json` — example maintenance history
- `resource_baseline.json` — initial water/fuel/food/power assumptions

Use these only for prototype demonstrations and software testing.
